Otosazu（オトサズ）

原稿を落とさず描き上げる ── 漫画制作のスケジュール管理ソフト ／ はじめにお読みください（試用版 0.1.2）

Otosazu は、CLIP STUDIO PAINT の漫画ファイルと連動して、ページ × 工程（下書き・ペン入れ・トーンなど）ごとの作業時間を記録するソフトです。 記録がたまるほど「このペースだと何日に完成するか」「締切に間に合わせるには今日なにをどれだけやるか」を正確に出せるようになります。

使える環境

  • Windows 10 / 11 のパソコン
  • CLIP STUDIO PAINT で作った漫画ファイル（拡張子 .cmc）。iPad 版の CLIP STUDIO のファイルは、今のところ読めません

インストールのしかた

  1. お渡しした Otosazu_0.1.2_x64-setup.exe をダブルクリックします。
  2. 「Windows によって PC が保護されました」という青い画面が出たら、「詳細情報」をクリックしてから「実行」を押してください。
    これは、まだ公式の署名（有料の証明書）を付けていない試用版のために出る表示です。お渡しした本人から受け取ったファイルであれば、そのまま進めて大丈夫です。
  3. インストーラーの案内に沿って進めます。管理者のパスワードは必要ありません。終わるとスタートメニューに「Otosazu」が追加されます。

はじめの使い方

1. 作品を登録する

Otosazu を開き、作品を追加 から CLIP STUDIO の漫画ファイル（.cmc）を選びます。ページの一覧とサムネイルが読み込まれます。 CLIP STUDIO でページを増やしたり並べ替えたりしても、作品を開くたびに自動で反映されます。

Otosazu は漫画ファイルを読むだけで、書き換えることはありません。CLIP STUDIO で開いている最中でも安心して使えます。

2. 作業時間を記録する

「進捗ボード」には、ページ（縦）× 工程（横）のマス目が並びます。これから作業するマスをクリックすると計測が始まります。 右上のタイマーで一時停止・停止ができ、止めると「この工程は完了しましたか？」と聞かれます。

  • ミニタイマー：右上の「⧉ ミニタイマー」で、CLIP STUDIO の上に小さなタイマーを常に表示できます。
  • ショートカット：どのアプリを使っていても Ctrl + Alt + Space で一時停止 / 再開できます（設定で変えられます）。
  • 止め忘れ対策：10 分間パソコンを操作しないと計測が一時停止し、「休憩していましたか？」と聞かれます。資料を読んでいたなら「作業していた」を選べば記録に含まれます。
  • 計測中に別のページを CLIP STUDIO で保存すると、「そのページを作業していますか？」と知らせます。

3. ページにタグを付ける

ページ名の横の「＋」から、「コマ多」「資料必要」「背景多め」などのタグを付けられます。タグは完成予測に使われます（例：コマ多 ＝ 1.3 倍かかる見込み）。 見開きページには「見開き」タグが自動で付きます。タグの種類や倍率は「設定 → タグ」で自由に変えられます。

4. 完成日を見る・締切から逆算する

完成日を見る曜日ごとの作業時間（例：平日 3 時間・土日 6 時間）を決めると、「早ければ／おそらく／遅ければ」の 3 つの完成見込み日を出します。
目標から逆算する締切日を入れると、1 日に必要な作業時間と今日のノルマを出し、「ペン入れの日」「混ぜる」など今日の進め方の案を並べます。気分で選んでください（どれを選んでも完成日は変わりません）。

時間は「1時間30分」のように表示します。「1:30」や「1.5h」の書き方がよければ、「設定 → 表示」で変えられます。

5. 工程を自分好みにする

工程ははじめ「下書き・ペン入れ・トーン」の 3 つです。「設定 → 工程」でネーム・ベタ・仕上げなどを追加したり、並べ替えたりできます。 追加した工程は、これから登録する作品で使われます。

6. 漫画ファイルを移動したり、名前を変えたりしたとき

作品を開くと「漫画ファイルが見つかりません」と表示されます。場所を指定し直す を押して、移動先の漫画ファイル（.cmc）を選んでください。 これまでの記録はそのまま引き継がれます（作品一覧のカードや、進捗ボード右上の「📁 場所を変更」からも指定できます）。

「作品を追加」から登録し直すと、記録が空の別の作品になってしまうので注意してください。

試用中のお願い

  • 使いにくいところ、分かりにくい言葉、「こうだったらいいのに」と思ったことを、気軽にメモしておいてください。
  • おかしな動きがあったときは、「設定 → データ → バックアップを作る」で作ったファイルを添えて、お渡しした本人まで連絡いただけると原因を調べやすくなります。
  • 完成予測は、記録が少ないうちは大まかな目安です。数ページ分の記録がたまると精度が上がります。

新しい版に入れ替えるとき

Otosazu を閉じてから、新しいインストーラーをダブルクリックするだけです。アンインストールは不要で、これまでの記録はそのまま引き継がれます。

データとアンインストール

  • 記録は、パソコンの中の 1 つのファイルに保存されています。場所は「設定 → データ → 保存場所を開く」で確認できます。
  • アンインストールは、Windows の「設定 → アプリ → インストールされているアプリ」から「Otosazu」を選びます。記録のファイルはそのまま残るので、入れ直せば続きから使えます。
