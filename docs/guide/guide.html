Otosazu（オトサズ）

原稿を落とさず描き上げる ── 漫画・イラスト制作のスケジュール管理ソフト ／ はじめにお読みください（2.2.0）

Otosazu は、CLIP STUDIO PAINT のファイルと連動して、ページ（イラストならファイル）× 工程（下書き・ペン入れ・トーンなど）ごとの作業時間を記録するソフトです。 記録がたまるほど「このペースだと何日に完成するか」「締切に間に合わせるには今日なにをどれだけやるか」を正確に出せるようになります。

使える環境

  • Windows 10 / 11、または Mac（macOS 11 以降）のパソコン
  • 漫画：CLIP STUDIO PAINT で作った漫画ファイル（拡張子 .cmc）
  • イラスト：CLIP STUDIO PAINT の.clip、または .psd のファイル
  • iPad 版の CLIP STUDIO で描いているファイルは、今のところ読めません

インストールのしかた

Windows

  1. ダウンロードした Otosazu_2.2.0_x64-setup.exe をダブルクリックします。
  2. 「Windows によって PC が保護されました」という青い画面が出たら、「詳細情報」をクリックしてから「実行」を押してください。
    Otosazu は無料のソフトで、有料の署名（証明書）を付けていないために出る表示です。配布ページからダウンロードしたファイルであれば、そのまま進めて大丈夫です。
  3. インストーラーの案内に沿って進めます。管理者のパスワードは必要ありません。終わるとスタートメニューに「Otosazu」が追加されます。

Mac

  1. ダウンロードした .dmg のファイル（Otosazu_2.2.0_universal.dmg）をダブルクリックし、出てきた窓の中の Otosazu を「アプリケーション」フォルダへドラッグします。
  2. アプリケーションフォルダの Otosazu を開くと、「Apple は、"Otosazu" にマルウェアが含まれていないことを検証できませんでした」と出ます。「完了」を押して閉じてください。
  3. 「システム設定 → プライバシーとセキュリティ」を開き、下のほうにある「"Otosazu" は Mac を保護するためにブロックされました」の横の「このまま開く」を押します。 確認が出たらもう一度「このまま開く」を押し、Mac のパスワード（または Touch ID）で許可すると起動します。
    Windows と同じく、有料の署名（Apple への登録）を付けていないために必要な手順です。最初の 1 回だけで、次からは普通に開けます。

はじめの使い方

1. 作品を登録する

Otosazu を開き、作品を追加 を押して、作品の種類を選びます。

漫画CLIP STUDIO の漫画ファイル（.cmc）を選びます。ページの一覧とサムネイルが読み込まれ、CLIP STUDIO でページを増やしたり並べ替えたりしても、作品を開くたびに自動で反映されます。
イラスト.clip / .psd のファイルを 1 つ以上選びます。依頼の連作や、表紙と挿絵などを 1 つの作品にまとめて締切を管理できます。あとから「＋ ファイルを追加」で増やしたり、ドラッグで並べ替えたりできます。
ファイルなしぬいぐるみ・模型・小説など、絵以外の制作に。作品名と、パーツや章の名前（1 行に 1 つ。「12」のように数字だけなら 1〜12 の番号）を入れて登録します。あとから「＋ パーツを追加」で増やしたり、名前をクリックして変えたり、ドラッグで並べ替えたりできます。工程は「設定 → 工程」で自分のセットを作っておきます（下の 7 を参照）。
Otosazu はファイルを読むだけで、書き換えることはありません。CLIP STUDIO で開いている最中でも安心して使えます。

2. 作業時間を記録する

「進捗ボード」には、ページ（縦）× 工程（横）のマス目が並びます。これから作業するマスをクリックすると計測が始まります。 右上のタイマーで一時停止・停止ができ、止めると「この工程は完了しましたか？」と聞かれます。

  • ミニタイマー：右上の「⧉ ミニタイマー」で、CLIP STUDIO の上に小さなタイマーを常に表示できます。
  • ショートカット：どのアプリを使っていても Ctrl + Alt + Space（Mac は control + option + space）で一時停止 / 再開できます（設定で変えられます）。
  • 止め忘れ対策：10 分間パソコンを操作しないと計測が一時停止し、「休憩していましたか？」と聞かれます。資料を読んでいたなら「作業していた」を選べば記録に含まれます。
  • 計測中に別のページを CLIP STUDIO で保存すると、「そのページを作業していますか？」と知らせます。
  • ポモドーロ：「設定 → タイマー」でオンにすると、計測した時間が 25 分たつごとに音と通知で知らせ、休憩する（5 分、4 回ごとに 15 分）か「続ける」を選べます。時間になっても計測は止まりません。休憩が終わったら「再開」で同じタスクの計測に戻ります。長さは設定で変えられます。

3. タグを付ける

ページ名（ファイル名）の横の「＋」から、特徴を表すタグを付けられます。タグは完成予測に使われます（例：コマ多 ＝ 1.3 倍かかる見込み）。 漫画なら「コマ多」「資料必要」、イラストなら「規模：大作」「背景：しっかり」「人数：2〜3人」などを用意しています。見開きページには「見開き」タグが自動で付きます。 タグの種類や倍率は「設定 → タグ」で自由に変えられます。 記録がたまると、倍率は実際にかかった時間に合わせて少しずつ自動で調整されます。

4. 完成日を見る・締切から逆算する

完成日を見る曜日ごとの作業時間（例：平日 3 時間・土日 6 時間）を決めると、「早ければ／おそらく／遅ければ」の 3 つの完成見込み日を出します。
目標から逆算する締切日を入れると、1 日に必要な作業時間と今日のノルマを出し、「ペン入れの日」「混ぜる」など今日の進め方の案を並べます。気分で選んでください（どれを選んでも完成日は変わりません）。

時間は「1時間30分」のように表示します。「1:30」や「1.5h」の書き方がよければ、「設定 → 表示」で変えられます。画面の色（ライト／ダーク）も同じところで選べます（はじめはパソコンの設定に合わせます）。

夜型の方へ：深夜まで作業する場合は、「設定 → 作業時間・休み → 1日の区切り」を朝 5 時などに変えてください。 深夜 2 時の作業が前の日の作業として数えられ、「今日のノルマ」も朝 5 時に切り替わります。

5. 月の予定を見る・カレンダーや紙で持ち歩く

「スケジュール」の「月の予定」タブでは、完成までの作業を日ごとに割り振り、「下書き p9〜p11・ペン入れ p5」のように月のカレンダーで見せます。 1 日の作業量は今日のノルマと同じ考え方で決まります（締切に間に合うなら締切までならし、間に合わなければ作業時間いっぱい）。 何時から作業するかまでは決めません。

進め方ページごと（p1 を全工程 → p2 を全工程 → …）、工程ごと（全ページの下書き → 全ページのペン入れ → …）、日をまたがないように（1 つのタスクがなるべく 1 日で終わるように選ぶ）から選べます。どれを選んでも完成日はほぼ同じです。
カレンダーに書き出すGoogle カレンダーやカレンダー.app などに取り込める .ics ファイルを作ります。1 日 1 件の終日の予定（と締切・完成予定）になり、スマホのカレンダーアプリでも見られます。
印刷・PDF月ごとのカレンダーを A4 横 1 枚ずつ印刷します。PDF にしたいときは、印刷先で「Microsoft Print to PDF」（Mac は「PDF として保存」）を選んでください。

取り込み方の例（Google カレンダー）：パソコンのブラウザで Google カレンダーを開き、設定（⚙）→「インポート／エクスポート」で .ics ファイルを選び、取り込み先のカレンダーを選んで「インポート」を押します。 Otosazu 用のカレンダーを作っておき、そこへ取り込むと、ほかの予定と区別しやすくなります。

書き出した予定は自動では更新されません。作業が進んだり予定が変わったりしたら、もう一度書き出して同じカレンダーに取り込んでください。 同じ日の予定は書き換わり、完成が早まって要らなくなった日の予定は消えます（前回書き出した内容を Otosazu が覚えているため。別のパソコンで書き出した場合は消えません）。

6. 統計で見直す

左の「統計」では、全作品の記録から、予測の前提になっている数字を確かめられます。

  • タグの倍率：最初に決めた倍率と、記録から見た実際の倍率を並べます。大きく違うタグには ⚠ が付くので、「設定 → タグ」で見直してください。
  • 曜日ごとの作業時間：直近 8 週間に実際に作業した時間の平均を、設定した作業時間と並べます。予定より少なければ、設定を実際に合わせると完成日の見込みが正確になります。
  • 工程ごとの基準時間：1 ページ（1 枚）あたり、各工程に実際どれくらいかかっているかを表示します。

7. 工程を自分好みにする

工程ははじめ、漫画が「下書き・ペン入れ・トーン」、イラストが「ラフ・線画・塗り・仕上げ」です。 「設定 → 工程」の「漫画」「イラスト」のタブで、ネーム・ベタ・下塗りなどを追加したり、並べ替えたりできます。 追加した工程は、これから登録する作品で使われます。

絵以外の制作には、＋ セットを追加 で自分の工程のセットを作ります。セットの名前（例：ガレージキット）と、作品を区切る 1 つ分の呼び方（例：パーツ、章）を決め、そのセットに工程（例：原型・複製・表面処理・塗装）を足してください。 作品を追加するときの「工程」で「＋ 新しいセットを作る…」を選んでも、この画面に来られます。 「設定 → タグ」では、タグのグループをどのセットで使うかを選べます。

8. ファイルを移動したり、名前を変えたりしたとき

漫画：作品を開くと「漫画ファイルが見つかりません」と表示されます。場所を指定し直す を押して、移動先の漫画ファイル（.cmc）を選んでください （作品一覧のカードや、進捗ボード右上の「📁 場所を変更」からも指定できます）。
イラスト：見つからないファイルの行に「⚠ 場所を指定」が出るので、押して移動先のファイルを選んでください。
どちらも、これまでの記録はそのまま引き継がれます。

「作品を追加」から登録し直すと、記録が空の別の作品になってしまうので注意してください。

困ったとき・ご意見

  • 完成予測は、記録が少ないうちは大まかな目安です。数ページ分の記録がたまると精度が上がります。
  • おかしな動きがあったときや、「こうだったらいいのに」というご意見は、配布ページに載せている連絡先までお寄せください（「設定 → このソフトについて」にも載せています）。 不具合のときは、「設定 → データ → バックアップを作る」で作ったファイルを添えていただけると原因を調べやすくなります。

新しい版に入れ替えるとき

新しい版が出ると、Otosazu を起動したときに「新しい版が出ています」とお知らせします。 更新する を押すと、ダウンロードとインストールが自動で進み、新しい版で開き直します。これまでの記録はそのまま引き継がれます。 お知らせは「設定 → データ → 起動時に新しい版を確認する」で止められます。

確認のとき、Otosazu は配布元（GitHub）から最新の版の情報だけを読み込みます。作業記録などのデータを送ることはありません。

手で入れ替えるとき（1.0.0 から新しい版にするときや、お知らせを止めているとき）は、Otosazu を閉じてから、新しいインストーラーをダブルクリックするだけです。アンインストールは不要です。 Mac では、新しい .dmg から Otosazu をアプリケーションフォルダへドラッグして「置き換える」を選びます。新しい版を初めて開くときは、インストールのときと同じ「このまま開く」の手順がもう一度必要です。

新しい版では、記録を保存するファイルの形が変わることがあります（初めて起動したときに自動で切り替わります）。 念のため、入れ替える前に古い版で「設定 → データ → バックアップを作る」をしておくと安心です。

データとアンインストール

  • 記録は、パソコンの中の 1 つのファイルに保存されています。場所は「設定 → データ → 保存場所を開く」で確認できます。
  • アンインストールは、Windows の「設定 → アプリ → インストールされているアプリ」から「Otosazu」を選びます。Mac ではアプリケーションフォルダの Otosazu をゴミ箱に入れます。どちらも記録のファイルはそのまま残るので、入れ直せば続きから使えます。
