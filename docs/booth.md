# BOOTH の商品ページ（叩き台）

## 商品説明

原稿を落とさず描き上げるための、漫画・イラスト制作のスケジュール管理ソフトです。（無料）

CLIP STUDIO PAINT のファイルと連動して、ページ（イラストならファイル）× 工程ごとに作業時間を記録します。
記録がたまるほど「このペースだと何日に完成するか」「締切に間に合わせるには今日なにをどれだけやるか」がはっきりします。

・漫画（.cmc）のページ一覧とサムネイルを自動で読み込み
・マスをクリックするだけで作業時間を計測
・完成日の見込みと、締切から逆算した「今日のノルマ」
・イラスト（.clip / .psd）にも対応

## 詳細

■ こんな方に
・締切前になって「あと何日かかるのか」が読めず、毎回ぎりぎりになる
・1 ページ（1 枚）を描くのに実際どれくらいかかっているか知りたい
・同人誌や依頼イラストの予定を、自分の実際のペースで立てたい

■ 主な機能
【進捗ボード】
CLIP STUDIO の漫画ファイル（.cmc）を選ぶだけで、ページの一覧とサムネイルを読み込みます。
ページ × 工程（下書き・ペン入れ・トーンなど）のマス目で、どこまで進んだかがひと目で分かります。
CLIP STUDIO でページを増やしたり並べ替えたりしても、自動で反映されます。

【作業時間の計測】
これから作業するマスをクリックすると計測が始まります。
・ミニタイマー：CLIP STUDIO の上に小さなタイマーを重ねて表示できます
・ショートカット：どのアプリを使っていてもキー操作で一時停止・再開できます
・止め忘れ対策：しばらく操作がないと計測を止めて「休憩していましたか？」と確認します
・計測中に別のページを保存すると「そのページを作業していますか？」とお知らせします

【完成日の予測】
曜日ごとの作業時間（例：平日 3 時間・土日 6 時間）から、「早ければ／おそらく／遅ければ」の 3 つの完成見込み日を出します。
これまでの記録から 1 ページあたりの時間を学ぶので、使うほど予測が正確になります。
「コマ多」「背景多め」などのタグを付けると、手間のかかるページも見込みに反映されます。

【締切から逆算】
締切日を入れると、1 日に必要な作業時間と「今日のノルマ」を出します。
「ペン入れの日」「トーンの日」「混ぜる」など、今日の進め方の案から気分で選べます（どれを選んでも完成日は変わりません）。

【作業記録】
日ごとの作業時間をカレンダー状に表示します。今週・先週の作業時間や、連続で作業した日数も分かります。
記録はあとから直したり、手で追加したりできます。

【イラストにも対応】
.clip / .psd のファイルを 1 つ以上まとめて 1 つの作品として登録できます。
依頼の連作や、表紙と挿絵などをまとめて締切を管理できます。工程は「ラフ・線画・塗り・仕上げ」から始まり、自由に変えられます。

【その他】
・工程は追加・並べ替え・名前の変更が自由にできます（ネーム・ベタ・下塗りなど）
・深夜まで作業する方向けに、「1日の区切り」を朝 5 時などに変えられます
・時間の表示は「1時間30分」「1:30」「1.5h」から選べます

■ 安心してお使いいただくために
・Otosazu は CLIP STUDIO のファイルを読むだけで、書き換えることはありません。CLIP STUDIO で開いている最中でも使えます。
・記録はお使いのパソコンの中にだけ保存されます。インターネットへの送信は一切ありません。
・記録は「設定 → データ → バックアップを作る」でいつでも 1 つのファイルに保存できます。
